# Weekly report - week of YYYY-MM-DD

> Independent educational project. Virtual money. Not investment advice. Published with a delay.

1. **Numbers:** return, volatility, drawdown, HHI / effective N, sectors, diversification ratio, 5/10/40 (generate with `scripts/weekly_report.py`).
2. **Mode and why:** NEUTRAL / CAUTION / DEFENSE / ATTACK / LOCK_IN.
3. **Decisions this week:** each with the memo link and the one-line reason.
4. **What went wrong:** one mistake or near-miss, stated plainly.
5. **Model change:** only if supported by out-of-sample data.
6. **Next week:** catalysts, event risk, planned trades.
